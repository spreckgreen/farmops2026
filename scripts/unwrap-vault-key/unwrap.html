Unwrap Bostead vault encryption key

Drop in the vault-key-export-*.json file exported from the admin UI, then touch the same YubiKey you used to wrap it. The decrypted VAULT_ENCRYPTION_KEY value will appear below for you to paste into your Docker environment.

Security note. Run this page from a trusted machine (open the file directly, or serve locally with python3 -m http.server from the same directory). Do not host it publicly. The decrypted key is never sent over the network. The page must be served from the same hostname (rpId) the YubiKey was enrolled against, or the browser will refuse the assertion.
